# Stock Market Dashboard

A Python application that connects to Yahoo Finance API to retrieve and display real-time stock market information and automated recommendations.

## Built With
- Python
- Yahoo Finance API (yfinance)
- MatplotLib

## Features
- Live Stock data retrieval for any ticker symbol
- Prices Trend Visualization over a customizable time period
- Automated buy/sell/hold based on trend analsyis
- Downloadable PNG chart output
